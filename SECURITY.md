# Security policy

## Scope

SEA LEVEL is a client-only static web application. It has no project-owned backend, account system, or secret-bearing server configuration. Pilot records and settings are stored in the browser's local storage.

## Reporting a vulnerability

Please do not include sensitive exploit details in a public issue. If private vulnerability reporting is enabled for the repository, use the repository's **Security** tab to submit a report. If it is not available, open a minimal issue asking for a private contact channel and omit exploit details until that channel is established.

Include the affected file or URL, the impact, and concise reproduction steps. Reports that include a safe fix or regression test are especially helpful.

## Supported versions

Only the latest `main` revision is actively maintained until a tagged release establishes a longer support window.
